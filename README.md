AREA OF REGION CALCULATOR
--------------------------

This is a fairly rudimental code, mostly built in snippets copy and pasted from sources. 

How it works: 

-Select the image you are using with files (will open automatically) 

-Select either pixel to distance scale, or if you want to work out the distance (if you don't already know) 

***I recommend using paint to get (x,y) pixel locations for each point** 

-Select as many points as you want to form a polygon 

-Number of vertices, pixel area, and area will be outputted. 

Thanks to anyone who uses this code!
